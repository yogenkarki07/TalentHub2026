# TalentHub Student Management System

## Overview
TalentHub is a console-based C++ application developed for managing student registrations, logins, and course enrollments.

## Features
- Student Registration
- Student Login
- Admin Registration
- Admin Login
- Password Validation
- Email Validation
- Course Enrollment
- Domestic and International Student Management
- Student Search
- Add Student
- Remove Student along with enrolled courses
- File Handling
- Professional Console UI

## Technologies Used
- C++
- STL Vector
- File Handling
- Modular Programming

## Password Rules
Passwords must contain:
- Minimum 8 characters
- Uppercase letter
- Lowercase letter
- Number
- Special character

## Sample Admin Emails
- Email must contain @talenthub.com
